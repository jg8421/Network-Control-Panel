# 线路控制台

一个通过 **Google Chrome** 打开的本机 Windows 线路面板。v1.1.0 将 ChatGPT 新连接、已有连接和普通代理分开显示，并在支持的土星配置中排除香港线路。

## 在其他电脑上使用

1. 将整个 ZIP 解压到一个普通文件夹，不要在压缩包预览窗口里直接运行。
2. 确认电脑已安装 **Google Chrome**，然后双击 **开始.vbs**。便携包自带 Node.js 运行环境，无需另外安装开发工具；启动器会直接使用 Chrome，不调用 Edge，也不修改 Windows 默认浏览器。
3. 在面板中检查后台连接。面板会尝试发现本机已运行的 Clash 兼容后台；没有找到时，可在设置中填写本机控制接口地址和必要的控制口令。

电脑需要已有已配置的土星通信或其他 Clash 兼容后台。面板接管日常查看和控制界面；代理内核仍由原后台提供。压缩包不包含任何电脑的订阅、账号、节点密码或控制口令，因此首次部署到另一台电脑时需使用那台电脑自己的配置。

如果后台没有运行，可使用面板内的后台启动入口。已配置的土星通信开机启动可以继续使用。面板安装后会添加当前用户登录后的静默启动入口，不新建系统服务。

## 安装常用入口

双击 **安装到本机.vbs**，程序会复制到当前用户的 `%LOCALAPPDATA%\JerryNetworkPanel\app`，并在桌面和开始菜单的 `Jerry Tools` 下创建 **线路控制台** 快捷方式，同时启用登录后静默启动。以后直接点快捷方式。安装不需要管理员权限；某些现有远程通道路由的暂停、恢复操作仍可能显示 Windows 管理员提示。

安装时只复制程序、前端、启动脚本和运行环境，不复制日志、状态、订阅或账号资料。重复安装会更新程序文件，个人设置保存在程序目录外。

## 登录后静默启动

安装后，Windows 当前用户登录时会通过启动文件夹中的 `JerryNetworkPanel.lnk` 运行 `AutoStart.vbs`。它只启动本机面板后台，不打开 Chrome 窗口或终端。要使用界面时，再点击桌面的“线路控制台”。既有土星通信启动入口继续负责代理后台。

安装会同时启用本面板这一条启动项的 Windows 启动许可。要关闭面板的自动启动，双击 **关闭自动启动.vbs**（或 `Disable-Autostart.vbs`）。此入口只删除目标和参数均匹配本面板的启动快捷方式，以及该条启动项自己的许可值。也可在安装脚本中传入 `-NoAutostart`，跳过创建或更新启动入口；已有入口需用关闭自动启动入口移除。

## 怎样选线路

- 在「选择线路」中先点 **ChatGPT** 或 **普通代理**，再在相应节点旁点「使用此线路」。ChatGPT 可设专用节点，也可以跟随普通代理。普通代理可以使用自动选择或故障转移组。
- 「ChatGPT 新连接」显示当前规则选出的节点。「ChatGPT 已有连接」按实际出口分组。切换后，已建立的连接会沿用旧线路，直到重新连接。
- 测速显示到 ChatGPT 测试地址的延迟。可按延迟排序，比较当前节点。

面板通过节点名称中的香港字样、地区旗帜以及 HK、HKG 等常用标记识别香港。在规则模式下，面板会检查已识别的土星本机配置，从节点、自动选择与故障转移组中移除香港，并在核心校验通过后应用。已建立的香港连接会被关闭。面板运行时每 30 秒检查一次，处理订阅更新后重新出现的节点。由其他客户端管理的配置需要在对应客户端设置地区排除，面板仍会禁用已识别的香港选项。地区未标注或标注有误的节点需要核对实际出口。

## 设置和运行位置

- 面板默认仅在本机 `http://127.0.0.1:18791` 提供界面。
- 个人设置和运行日志保存在 `%LOCALAPPDATA%\JerryNetworkPanel`，不在源代码压缩包中。
- API 控制口令如有填写，仅供本机连接使用，不会显示在状态接口或作为发布内容打包。
- 关闭浏览器窗口会关闭界面；已启动的轻量本地面板进程可继续运行，便于再次快速打开。要完全退出面板，双击 **停止面板.vbs**；它仅请求关闭此面板，原代理后台会继续运行。

本包不向互联网发布面板，不修改路由器或防火墙，也不公开本机代理控制接口。

## 源码和手动运行

主要代码在 `server.mjs`、`lib/`、`public/` 和 `scripts/`。便携包已包含 Node.js、YAML 依赖及其许可证。使用 GitHub 源码时，请先安装 Node.js 22 或更高版本并运行 `npm ci`。

开发者可直接运行：

```powershell
npm start -- --port 18791
```

使用 Google Chrome 打开 `http://127.0.0.1:18791`。要静默检查启动，可运行：

```powershell
powershell.exe -NoProfile -ExecutionPolicy Bypass -File .\scripts\Start-Panel.ps1 -NoBrowser
```

如默认端口已被其他程序使用，可给启动脚本传入 `-Port 18792`。启动器只复用身份匹配的现有面板，不会结束其他程序。

## 升级和移除

解压新版并运行“安装到本机”。安装器会先关闭正在运行的旧版面板，再部署新文件。首次修改土星配置前，程序会在本机状态目录保留 `config.before-region-policy.yaml`，供需要时恢复。

不再使用时，先双击 `Disable-Autostart.vbs` 关闭自动启动，再双击“停止面板.vbs”，之后移除桌面、开始菜单的快捷方式和安装目录即可。原土星通信、订阅及既有开机设置独立保留。
